# KINETIA — Dale vida a tus imágenes

Aplicación web que anima fotos y videos cortos a partir de una segmentación semántica entrenada por el equipo. Proyecto de Inteligencia Artificial para ExpoUNINPAHU 2026.

**Estado:** en construcción. El avance está en [docs/PROGRESO.md](docs/PROGRESO.md) y las interfaces en [docs/CONTRATOS.md](docs/CONTRATOS.md).
